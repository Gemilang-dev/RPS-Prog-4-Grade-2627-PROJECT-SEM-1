C++ Practice Form: Terminal & Comments

Validate your grasp of g++ compilation commands, binary execution, flags, and C++ comment mechanics.

Stress-Free Learning (No Grades): This exercise is not a scored or graded test. It is a self-assessment tool to build your confidence before compiling and debugging systems code independently in the terminal.
Question 1 Terminal Command
Write the complete terminal command to compile program.cpp using g++ and output an executable binary named app!
Hint: Use the compiler binary g++, specify the source file, and supply the -o flag followed by the output executable name.
Question 2 Program Execution
Once compilation succeeds, what terminal command executes the binary app located in the current folder on Linux / macOS?
Hint: In Unix-like shells, local executables require the relative path prefix dot-slash (./).
Question 3 Compiler Flags
Which recommended g++ flag turns on all standard compiler warnings so potential bugs and mistakes are caught early?
Hint: Short for "Warnings All", starts with a capital 'W'.
Question 4 C++ Standards
Write the compiler flag that instructs g++ to compile code using the ISO C++17 standard!
Hint: Format is -std=c++XX where XX is the two-digit year.
Question 5 Anatomy of Comments
Explain the difference in delimiters between single-line comments and multi-line block comments in C++!
Hint: Mention double slashes and slash-asterisk pairs.
Question 6 Comment Traps
Can block comments in C++ be nested like /* outer /* inner */ still comment? */? What happens if you try?
Hint: Which closing tag does the compiler encounter first?
Question 7 Preprocessor
At what compilation stage are C++ comments stripped out? Do comments increase the size of the compiled binary?
Hint: Remember the 4 stages (Preprocessor, Compiler, Assembler, Linker).
Question 8 Workflow Chaining
Write a single-line terminal command that compiles program.cpp into app and immediately runs it ONLY IF the compilation succeeded!
Hint: Use the logical operator && between the compilation command and the execution command.
Question 9 Function Documentation
Provide an example of clean documentation comments (Doxygen style) placed above a simple math function!
Hint: Typical industry format uses /** ... */ with @brief, @param, and @return.
